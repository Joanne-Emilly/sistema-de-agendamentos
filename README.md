
# Sistema Web de Agendamento Escolar

## Sobre o Projeto

O Sistema Web de Agendamento Escolar tem como objetivo organizar e facilitar o agendamento e a utilização dos espaços escolares, contribuindo para o planejamento das atividades pedagógicas e para a redução de conflitos de horários.

## Espaços Disponíveis

O sistema contemplará, inicialmente, os seguintes espaços:

- Laboratório de Informática;
- Laboratório de Biologia;
- Biblioteca.

## Objetivo

Facilitar o planejamento do uso dos espaços escolares, reduzir conflitos de horários e permitir a consulta dos agendamentos e de seus respectivos responsáveis.

## Funcionalidades Previstas

- Visualizar os espaços disponíveis;
- Solicitar agendamentos informando data, horário, finalidade e responsável;
- Consultar as próximas reservas;
- Identificar possíveis conflitos de horários;
- Acompanhar o status dos agendamentos.

## Tecnologias Previstas

- **Figma:** criação dos protótipos das interfaces;
- **HTML:** estrutura das páginas;
- **CSS:** estilização e responsividade;
- **JavaScript:** interações e validações;
- **Git e GitHub:** versionamento do código e colaboração entre as equipes.
