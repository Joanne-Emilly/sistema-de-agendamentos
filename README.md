# Sistema Web de Agendamento Escolar

## Sobre o projeto

Sistema web destinado a organizar o agendamento e a utilização dos espaços escolares.

## Espaços disponíveis

- Laboratório de Informática
- Laboratório de Biologia
- Biblioteca

## Objetivo

Facilitar o planejamento do uso dos espaços, reduzir conflitos de horários e permitir a consulta das reservas e de seus responsáveis.

## Funcionalidades previstas

- Visualizar os espaços disponíveis.
- Solicitar agendamentos com data, horário, finalidade e responsável.
- Consultar as próximas reservas.
- Identificar conflitos de horários.
- Acompanhar o status dos agendamentos.

## Tecnologias previstas

- Figma: prototipação da interface.
- HTML: estrutura das páginas.
- CSS: estilização e responsividade.
- JavaScript: interações e validações.
- Git e GitHub: versionamento e colaboração.
